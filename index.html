    Modo automático

    Con el modo automático el ESP32 enciende la bomba cuando un depósito baja del umbral y la apaga sola al llegar al nivel de paro. Aun en manual, la bomba siempre se apaga sola al llenarse.

    Escenario: tubería rota hacia los bebederos

    Rompe el tramo principal que lleva el agua a los tres bebederos y enciende sus bombas. El agua sale del tanque de reserva pero ningún bebedero sube. El ESP32 lo detecta, apaga las bombas y avisa.

    Detección de fugas

    5 min

    Si en ese tiempo el depósito sube menos del 25 % de lo que debería (caudal × tiempo), se considera fuga.

      Conexiones sugeridas (GPIO)

      DepósitoTRIGECHOActuadorReléEstado

      ECHO usa los pines 34, 35, 36 y 39, que solo sirven como entrada. Los GPIO 16 y 17 están libres en el ESP32-WROOM (no en WROVER).

      Cómo se calcula el nivel

      El HC-SR04 mide el tiempo del eco: d = t × 0.0343 / 2 (cm). Con la distancia al fondo vacío H y la distancia cuando está lleno d_lleno:

      nivel % = (H − d) / (H − d_lleno) × 100

      El HC-SR04 no mide menos de 2 cm: dejen al menos 2–3 cm entre el sensor y el agua cuando el depósito esté lleno.

      Notas para armar la maqueta

      • El ECHO del HC-SR04 sale a 5 V si lo alimentan con 5 V, y el ESP32 trabaja a 3.3 V. Aliméntenlo con 3.3 V (su modelo acepta 3–5.5 V) o pongan un divisor de 1 kΩ y 2 kΩ en ECHO.
      • Las bombas no se conectan a un pin del ESP32: van por el contacto COM/NO del relé hacia el riel de 5 V del MB102.
      • Cada mini bomba consume 100–200 mA. Si van a encender varias a la vez, alimenten el MB102 con un adaptador de 9–12 V en vez de USB.
      • Las mini bombas son sumergibles: van dentro del depósito de donde sacan el agua. En la escena están afuera para que se vean.
      • Si el ESP32 pierde el WiFi, el control sigue funcionando porque la lógica corre en el ESP32. Solo se pierde el reporte a la app.
      Lógica de detección de fuga (Arduino) 
      // Se revisa cada ciclo mientras la bomba está encendida
if (bombaOn[i]) {
  float min = (millis() - tInicio[i]) / 60000.0;
  if (min >= VENTANA_MIN) {
    float subio    = litros(destino[i]) - litrosInicio[i]
                   + salidaConocida[i];   // otras bombas + consumo
    float esperado = CAUDAL_LPM[i] * min;
    if (subio < esperado * 0.25) {
      digitalWrite(RELE[i], LOW);        // apaga la bomba
      bloqueada[i] = true;
      enviarAlerta("Posible tubería dañada", i);
    } else {
      tInicio[i] = millis();             // nueva ventana
      litrosInicio[i] = litros(destino[i]);
      salidaConocida[i] = 0;
    }
  }
}
